Блокнот для Android (Kotlin + Jetpack Compose)

Как получить APK без Android Studio:
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository, имя notepad).
2. Распакуйте этот архив. В репозитории нажмите Add file -> Upload files и перетащите ВСЁ содержимое
   папки (включая скрытую папку .github), затем Commit changes.
3. Откройте вкладку Actions -> Build APK. Сборка идёт 5-10 минут.
4. Когда появится зелёная галочка, откройте запуск и скачайте файл notepad-apk внизу страницы.
5. Распакуйте его и установите app-debug.apk на телефон (разрешите установку из этого источника).

Если сборка упала (красный крестик): откройте шаг "Run gradle assembleDebug" и пришлите ошибку Claude.
